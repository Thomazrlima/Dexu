# Protótipo sem backend ou banco próprios

O primeiro protótipo usa dados auditados e versionados de SoulSilver e salva times no navegador, com exportação e importação por arquivo. Backend e banco de dados foram considerados para antecipar contas e recursos sociais, mas nenhuma função do primeiro marco exige armazenamento remoto; evitamos esse custo enquanto preservamos uma rota explícita de migração dos times locais para futuras contas.
