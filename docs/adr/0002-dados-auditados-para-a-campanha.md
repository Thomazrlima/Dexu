# Dados auditados para a campanha

O Dexu servirá ao MVP um conjunto próprio, versionado e verificado de dados de SoulSilver, usando a PokéAPI como uma fonte inicial e complementando o que ela não comprova. Consultas diretas à API durante o uso, mesmo com cache e correções, deixariam a elegibilidade antes do confronto com Red dependente de dados agrupados por versões e de mudanças externas; a escolha por um conjunto auditado preserva resultados estáveis e explicáveis. O formato de armazenamento ainda está em aberto.
