# Preservar times após correções dos dados

Quando uma atualização dos dados auditados torna inválida uma escolha de um time salvo, o Dexu preserva o time e explica a inconsistência para que o jogador a corrija. Remover escolhas automaticamente causaria perda irreversível do trabalho do usuário; congelar os times em dados antigos manteria como válidas opções que o produto passou a saber que não são. Esta regra também vale para times restaurados de backup.
