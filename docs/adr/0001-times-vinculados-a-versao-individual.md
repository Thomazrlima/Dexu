# Times vinculados a uma versão individual

Cada time é criado para uma versão jogável fixa, começando por SoulSilver. Versões próximas, como HeartGold e SoulSilver, podem compartilhar regras, mas a disponibilidade de Pokémon e golpes para a campanha é avaliada na versão do time. Consideramos vincular o time ao par e deixar a versão como filtro mutável; isso permitiria que uma troca de filtro invalidasse escolhas já salvas e enfraqueceria a promessa de planejar uma campanha específica.
